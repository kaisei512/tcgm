# TCGM

Trading card cash flow and net assets manager for personal use.

## Usage

Open `index.html` in a browser.

Data is stored in the browser's `localStorage`. Use the export/import buttons to back up or move data.

## MVP Scope

- Monthly cash flow dashboard
- Net assets dashboard
- Inventory tracking by purpose
- Sale registration with channel fees
- Expense registration
- BOX opening as asset conversion
